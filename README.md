# Sales Data Analysis

A Python-based sales data analysis project developed using Pandas as part of the Developers Arena Internship.

## Project Overview

This project analyzes sales data to understand overall sales performance, product performance, and regional sales performance.

The analysis includes:

- Loading and exploring the sales dataset
- Checking data structure and data types
- Checking missing values and duplicate records
- Converting the Date column to datetime format
- Calculating total sales
- Calculating total quantity sold
- Identifying the best-selling product
- Identifying the best-performing region
- Generating business insights

## Technologies Used

- Python
- Pandas
- Google Colab
- GitHub

## Dataset

The dataset contains 100 sales records and 7 columns:

- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales

## Key Results

- **Total Sales:** ₹12,365,048.00
- **Total Quantity Sold:** 478 units
- **Best-Selling Product:** Laptop
- **Best-Selling Quantity:** 136 units
- **Best-Performing Region:** North
