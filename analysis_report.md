
# Sales Data Analysis Report

## 1. Project Overview

This project analyzes sales data using Python and pandas. The analysis focuses on understanding overall sales performance, quantity sold, product performance, and regional sales performance.

## 2. Dataset

The dataset contains sales records with the following columns:

- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales

## 3. Data Exploration

The dataset was explored by checking:

- Number of rows and columns
- Column names
- Data types
- First few records
- Basic statistical information

## 4. Data Cleaning

The dataset was checked for:

- Missing values
- Duplicate records
- Correct data types

The Date column was converted to datetime format to support date-based analysis.

## 5. Sales Analysis

The following metrics were calculated:

- Total Sales
- Total Quantity Sold
- Best-Selling Product
- High Quantity Sales
- Best-Performing Region

## 6. Business Insights

1. The best-selling product was identified based on total quantity sold.
2. Total sales were calculated across all sales records.
3. Total quantity sold was calculated across all products.
4. The highest-performing region was identified based on total sales.
5. Product and regional analysis helps identify areas of stronger sales performance.

## 7. Conclusion

The analysis provides a basic overview of sales performance using Python and pandas. The calculated metrics and insights can help understand product and regional sales patterns.
